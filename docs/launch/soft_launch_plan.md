# Soft Launch Plan

Goal: open testing in Thailand with controlled content cadence and no paid user acquisition.

## Launch Shape

- Country: Thailand
- Platform: Android
- Store track: Google Play open testing or limited production rollout
- Monetization: gacha IAP only after purchase validation is proven
- Ads: none
- PvP: none

## Week 1 Priorities

- Monitor crash-free sessions.
- Monitor tutorial start to first battle start.
- Monitor first battle win and first upgrade.
- Monitor wave fail spikes around boss waves.
- Monitor purchase validation and duplicate receipt protection.
- Monitor backend costs and Edge Function error rates.

## Content Cadence

- Banner: one launch banner
- Event: one small login/offline reward event if backend cost is stable
- Balance patch: wave 1-30 only unless critical issue appears

## Stop Conditions

- Critical crash spike.
- Duplicate paid grant.
- Economy exploit.
- Purchase validation outage.
- Backend cost spike beyond owner threshold.
- Store policy/compliance issue.

## Owner Decisions Needed

- Paid gacha enable date.
- Support staffing window.
- Public launch country expansion after Thailand.
- Whether to wipe closed-test data before soft launch.
