# Tester Feedback Form Template

Use this to create Google Form, Typeform, Notion form, or similar.

## Required Fields

- Tester name or nickname
- Device model
- Android version
- App version
- Language used: Thai / English
- Did the game launch without black screen?
- Time to understand first action: under 30 seconds / 30-60 seconds / over 60 seconds
- Did you win the first battle?
- Did you complete the first upgrade?
- Where did you get stuck?
- Was any Thai text clipped or hard to read?
- Did any sprite look missing or wrong?
- Did gacha odds appear before pull?
- Did purchase sandbox flow work? license testers only
- Crash or freeze details
- Screenshot/video upload
- One sentence: what is this game?
- Score 1-5: fun
- Score 1-5: clarity
- Score 1-5: performance
- Free notes
