# Launch Monitoring Checklist

## Firebase

- `tutorial_start`
- `first_battle_start`
- `first_battle_win`
- `first_upgrade`
- `wave_start`
- `wave_clear`
- `wave_fail`
- `offline_claim`
- `gacha_view`
- `gacha_pull`
- `purchase_start`
- `purchase_success`
- `purchase_fail`

## Crashlytics

- Crash-free sessions
- Crash-free users
- Top crash signatures
- App start crash/black screen reports
- Android version/device clusters

## Supabase

- Edge Function error rate
- Database CPU and memory
- Auth anonymous account creation
- Purchase validation function health
- Economy ledger write rate
- Duplicate idempotency key collisions
- Gacha pull request rate

## Google Play

- Install failures
- Android vitals
- Pre-launch report
- ANR/crash reports
- Purchase order status
- User reviews/support emails

## Manual Watch

- Support inbox monitored during rollout.
- Known issue list updated.
- Rollback owner available.
- Backend operator available.
